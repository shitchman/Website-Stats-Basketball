# 2K React App

## Development Startup

Run these commands from the `Frontend` folder:

```powershell
cd Frontend
```

Install frontend dependencies once:

```powershell
npm install
```

Install backend dependencies in the project virtual environment once:

```powershell
..\.venv\Scripts\python.exe -m pip install -r ..\Backend\requirements.txt
```

Open two terminals in the `Frontend` folder and run:

```powershell
npm run backend:dev
```

```powershell
npm run dev
```

Open `http://localhost:5173`. The API runs at `http://localhost:8000`.

Python bytecode generated by the backend is redirected to the project-level `.pycache` folder via `PYTHONPYCACHEPREFIX`, so `__pycache__` folders do not spread through the source tree. Existing `__pycache__` folders can be deleted once the backend is stopped.
